# 中根研究室ウェブサイト

電気通信大学 中根研究室のウェブサイトです。GitHub Pages で公開します。
デザインは研究室の学生の案をもとにしています。旧サイト（Ameba Ownd）のお知らせ 221 件、メンバー紹介、論文リスト、研究紹介、アクセス、リンクをすべて移し、英語版も付けてあります（右上の English ボタンで切り替え）。

---

## 更新のしかた（おすすめ：入力フォームで編集する）

**Pages CMS** というサービスを使うと、ブラウザの入力フォームから更新できます。ファイルの書き方を覚える必要はありません。保存すると GitHub に記録され、1〜2 分でサイトに反映されます。

### 最初の 1 回だけ
1. https://app.pagescms.org を開き、「Sign in with GitHub」で GitHub アカウントでログインする。
2. 案内に従って、Pages CMS（GitHub App）を研究室の Organization にインストールする。
3. 一覧からこのサイトのリポジトリを選ぶ。設定ファイル（`.pages.yml`）はすでに入っているので、左側にメニューが出ます。

### 左側のメニューでできること

| メニュー | できること |
|---|---|
| お知らせ (News) | 記事の追加・修正。写真もここからアップロード |
| 論文リスト (Papers) | 論文の追加。年ごとに自動で並ぶので、どこに足してもよい |
| 代表的な論文の解説 | 解説付きの論文の追加・修正 |
| リンク・共同研究先 (Links) | 共同研究先などの追加。区分（学内／学外／プロジェクト）を選ぶ |
| 研究室の発信 | リンクページ上部の YouTube・SNS などのリンク |
| メンバー (Members) | 学生の追加・削除、学年やテーマの変更、写真の差し替え |
| 教員（中根） | 略歴・担当授業・ひとこと |
| 学生の研究テーマ | 卒研・修論テーマの追加 |
| 集合写真 | 写真と説明の追加 |
| 受賞 (Awards) | 受賞の追加。年月（例 2026-10）で新しい順に並ぶ |
| 研究費 (Funding) | 研究費の追加 |
| トップページの動画 | YouTube 動画の追加。何本でも入れられます。リストが 3 本より多いと、ページを開くたびにランダムに 3 本を選んで表示します |
| 研究／アクセス／論文ページの本文 | 長い文章の修正 |
| フッターの外部リンク | ページ最下部のリンク |
| 翻訳の用語集 (Glossary) | 自動翻訳で使う、用語や学外の人名の英語表記 |

### 英語について
各項目に「(English)」の欄があります。**空欄のままで大丈夫**です。

- **自動翻訳を設定してある場合**（下の「英語の自動翻訳」）：保存して数分たつと、空欄だった英語が自動で入ります。
- 設定していない場合：空欄の項目は、英語モードでも日本語で表示されます（記事本文には「This content is available in Japanese only.」と小さく出ます）。
- 自分で書いた英語は、自動翻訳で上書きされません。
- 人名のローマ字（メンバーや卒業生の Name (English)）だけは自動で入りません。読み間違いを避けるためなので、ここは手で入れてください。

### 年度はじめの作業の例
- 「メンバー」で学年を 1 つ上げる（M1 → M2 など）。卒業生は削除して、「学生の研究テーマ」に卒論・修論を追加する。
- 新しいメンバーを追加し、写真をアップロードする。写真の切り抜き位置は「50% 30%」（横% 縦%）のように調整する。

### 気をつけること
- お知らせの日付は、入力した日時（日本時間）がそのまま表示されます。日付を変えると、その記事の URL（`/news/日付-名前/`）も変わります。
- 研究ページ・アクセスページの本文は、写真の並べ方などを細かく組んであります。入力フォームで保存すると、写真が縦一列になることがあります（表示は崩れません）。
- 消したものを戻したいときは、GitHub のリポジトリの「Commits」から以前の状態を見られます。困ったら Claude に「この変更を元に戻したい」と相談してください。

## 英語の自動翻訳

日本語で更新すると、英語の欄が空の項目を見つけて、自動で英訳して書き込む仕組みが入っています（`.github/workflows/auto-translate.yml` と `tools/auto_translate.py`）。翻訳には Claude の API を使います。

### 最初の 1 回だけ：API キーを登録する
API キーを登録するまでは、この仕組みは何もしません（サイトには影響しません）。

1. **Claude Console**（https://platform.claude.com ）でアカウントを作る。claude.ai の契約とは別の、API 用の画面です。
2. Settings → Billing で「Buy credits」を押し、クレジットを買う（前払い式。少額でかまいません）。
   - **Claude の Max・Ultra・Team プランを契約している場合は、買わなくてすみます。** プランに毎月の API クレジットが付いているので、claude.ai の Settings → Billing（Team は Organization settings → Billing）の「API credits」で「Link organization」を押し、この Console の組織を選んでください（2026 年 11 月時点。Free・Pro・Enterprise は対象外）。説明：https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-ultra-and-team-plans
3. API keys の画面で「Create Key」を押し、表示されたキー（`sk-ant-…`）をコピーする。キーは 1 度しか表示されません。
4. GitHub でこのリポジトリを開き、Settings → Secrets and variables → Actions → 「New repository secret」。
   Name に **`ANTHROPIC_API_KEY`**、Secret にコピーしたキーを貼り、「Add secret」を押す。
5. 確認：リポジトリの「Actions」タブ → 左の「英語の自動翻訳 (Auto-translate)」→「Run workflow」。
   緑のチェックになれば準備完了です。実行結果のページに、何を翻訳したかが日本語で出ます。

API キーは他人に見せないでください（Secret に入れたキーは、GitHub 上でも誰にも表示されません）。

### ふだんの流れ
1. 編集画面（Pages CMS）で、日本語だけ書いて保存する。
2. 1〜2 分でサイトに日本語が出る。さらに数分すると、英語が自動で入ってサイトに反映される。
3. 英語を直したいときは、編集画面を開き直して English の欄を書き換える。自分で直した英語は、そのあと上書きされません。

### 知っておくとよいこと
- **日本語を書き直したとき**：英語が自動翻訳のままなら、英語も作り直されます。自分で英語を直してあった項目は、そのまま残ります（英語も変えたいときは、English の欄を空にして保存すると、作り直されます）。
- **用語や人名の英語表記**：編集画面の「翻訳の用語集」に足すと、次の翻訳から使われます。研究室のメンバーと卒業生の名前は、メンバー一覧・研究テーマ一覧の Name (English) から自動で読み取ります。お知らせなどでは下の名前（Atsuya など）、受賞一覧などではフルネームで書くようにしてあります。下の名前が同じ 2 人（上村くんと小倉くん）は、上村くんを「Naoki」、小倉くんを「Naoki Ogura」と書き分けます。名簿に英語名がない人と学外の方は、名字のままです。
- **費用**：翻訳した分だけ、Claude Console のクレジットから引かれます。お知らせ 1 件で数円程度です（2026 年 11 月時点、モデル Claude Sonnet 5.5）。クレジットが切れると翻訳は止まり、その項目は日本語のまま表示されます。
- **うまくいかないとき**：「Actions」タブの「英語の自動翻訳」に赤い × が出ます。開くと理由が日本語で書いてあります（キーの間違い、クレジット不足など）。
- **GitHub Desktop を使う人へ**：自動翻訳が GitHub 上のファイルを書き換えるので、作業の前に必ず「Fetch origin」→「Pull origin」をしてください。
- 翻訳に使うモデルは `.github/workflows/auto-translate.yml` の `TRANSLATE_MODEL` で変えられます。

## もう 1 つの方法：GitHub 上でファイルを直接編集する

Pages CMS を使わずに、GitHub のページでファイルを開き、鉛筆アイコンで直接書き換えることもできます。

| 変えたいもの | ファイル |
|---|---|
| お知らせ | `_posts/` に 1 記事 1 ファイル（`templates/news-template.md` をコピー。ファイル名は `2026-11-10-gakkai.md` のように日付＋半角英数字） |
| 論文 | `_data/papers.yml` |
| 代表的な論文の解説 | `_data/papers_featured.yml` |
| リンク | `_data/links.yml`、`_data/outreach.yml` |
| メンバー | `_data/members.yml`（学年の表示名は `_data/grades.yml`） |
| 教員 | `_data/pi.yml` |
| 卒研・修論 | `_data/theses.yml` |
| 集合写真 | `_data/group_photos.yml` |
| 受賞・研究費 | `_data/awards.yml`、`_data/funding.yml` |
| 動画 | `_data/videos.yml`（一度に並べる本数は `_config.yml` の `video_count`） |
| 翻訳の用語集 | `_data/glossary.yml` |
| 上部メニュー・フッター | `_data/navigation.yml`、`_data/social.yml` |
| 研究・アクセス・論文ページの文章 | `research/index.html`、`access/index.html`、`papers/index.html` |
| トップページの文章 | `index.html` |
| 色・文字・レイアウト | `assets/css/style.css` |

`.yml` ファイルは、すでにある 1 件分をコピーして書き換えるのが確実です。行頭のスペース（字下げ）をそろえないとエラーになります。
エラーがあっても公開中のサイトは壊れず、前の状態のまま表示されます。リポジトリの「Actions」タブに赤い × が出るので、直前の変更を見直してください。

写真の置き場所：
- `assets/img/news/` … 新しいお知らせ用
- `assets/img/people/` … メンバー写真・集合写真
- `assets/img/archive/`、`assets/img/research/`、`assets/img/access/` … 旧サイトから移した写真（触らなくてよい）

## 公開のしかた（最初の 1 回だけ）

1. GitHub で研究室用の **Organization** を作る（このサイトは `nakane-lab-uec`）。先生と担当の学生を Owner にしておく。
2. Organization の中にリポジトリを作る。名前は **`nakane-lab-uec.github.io`**（Organization名 + `.github.io`）、Public。
3. GitHub Desktop でリポジトリを取り込み、このフォルダの中身をすべて入れて「Commit to main」→「Push origin」。
   （ブラウザからのアップロードは 1 回 100 ファイルまでなので、最初だけ GitHub Desktop を使います）
4. リポジトリの「Settings」→「Pages」で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存。
5. 数分後に `https://nakane-lab-uec.github.io/` で公開されます（`_config.yml` の `url:` は設定済み）。

### 独自ドメインを使う場合
「Settings」→「Pages」→「Custom domain」にドメインを入力し、ドメイン管理会社の DNS を GitHub の案内どおりに設定して、`_config.yml` の `url:` を書き換えます。

## メモ
- お知らせの URL は `/news/日付-名前/` です（例：`/news/20261009-59316317/`。旧サイトから移した記事の後半は旧サイトの記事番号）。
- 記事の日時は、ファイルの中では `2026-11-16 21:49:00 +0000` のように書かれています。末尾は +0000 ですが、入力したとおりの日本時間として扱っています（編集画面がこの形で保存するため。`_config.yml` の `timezone: UTC` はこのための設定なので、変えないでください）。
- `news/20261024-000943/` など 4 つのフォルダは、日付の表示を直したときに URL が変わった記事の、古い URL から新しい URL への案内です。消さないでください。
- 旧サイトのアクセスページの地図は渋谷を指していたため、「電気通信大学」で表示するように直してあります。
- 写真は旧サイトから取り出して、長辺 1600px に縮めてあります（合計約 80MB）。
- 英語版は旧サイトの日本語から翻訳したものです。人名は、確実なもの以外は姓のみにしています。
